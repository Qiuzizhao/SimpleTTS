# SimpleTTS — 不方便开口患者的文字朗读工具

面向口腔术后等不便开口的患者：**打字或点按短语，设备用语音替你说出来**，与医护、家属面对面沟通。

- 中文（普通话）语音，默认微软"晓晓"神经语音，音质自然
- 断网自动降级为浏览器本地语音，功能永不断
- 常用短语可增删、恢复默认；重复朗读秒出（三层缓存）
- 网页版：浏览器打开即用，电脑 / 平板 / 手机通用

## 快速开始

环境要求：Windows / macOS / Linux + Python 3.9+

### Windows
双击 `start.bat`（首次运行会自动安装依赖并打开浏览器）。

### 手机 / 平板（与电脑同一 WiFi）
双击 `start-lan.bat`，用显示的局域网地址访问（如被拦截请放行防火墙）。

### 手动启动
```bash
pip install -r requirements.txt
python server.py
# 浏览器打开 http://localhost:8000
```

> 提示：直接双击 `index.html` 也能用，但只能使用本机语音（无"晓晓"）。

## 功能

- 大字输入框 + 一键朗读 / 停止
- 口腔术后常用短语：点击即朗读，**可增删、恢复默认**；保存在**服务端**（多设备同步），本机留离线备份
- 语速 / 音量 / 音色调节（晓晓、云希等 6 种中文音色）
- 断网自动降级为本地语音，每 8 秒自动重连
- 语音三层缓存：服务端磁盘 + 浏览器长缓存 + 页面预热，重复朗读秒出


## 部署到服务器

服务端支持 HTTP 访问即可，任选一种：

```bash
# 方式一：直接运行（监听所有网卡）
HOST=0.0.0.0 PORT=8000 python server.py

# 方式二：Docker（数据持久化到数据卷）
docker build -t simpletts .
docker run -d --name simpletts -p 8000:8000 -v simpletts-data:/app/data simpletts
```

- 常用短语和语音缓存都存于 `data/` 目录，Docker 挂载该卷后**重启/换机器不丢**。
- 服务器上访问需联网（晓晓由微软在线合成）；无外网时页面自动降级为浏览器语音。
- 公网使用建议放在 **HTTPS 反向代理**（Caddy / Nginx / 宝塔）后面。当前服务**暂无鉴权**，请勿直接暴露公网端口；如需要访问令牌，可以告诉我加上。

## 隐私说明

- "晓晓"语音由微软在线合成，文字会发送至微软官方接口，不落任何第三方存储
- 常用短语保存在服务端 `data/phrases.json`（本机留离线备份），语音缓存保存在 `data/cache/`，均可随时删除

## 技术栈

FastAPI + edge-tts + 原生前端（无框架），单机即可运行。
